# 11주차 모듈 1: BMI 건강정보 저장하기

## 이 프로그램은 무엇을 하나요?

이 프로그램은 **두 사람의 건강정보 카드를 만들고, 네 가지 파일에 각각 저장한 다음, 다시 읽어서 원래 정보와 같은지 확인**합니다.

작업 순서는 다음과 같습니다.

1. 두 사람의 건강정보를 입력합니다.
2. 각 정보에 식별번호를 붙여 목록에 추가하고 화면에 출력합니다.
3. 목록을 JSON, CSV, TXT, PICKLE 파일에 각각 저장합니다.
4. 각 파일을 다시 읽어서 화면에 출력합니다.
5. 읽어 온 정보가 저장하기 전 원본과 같은지 비교합니다.

> 현재 BMI와 비만도 상태는 예시 값으로 직접 입력되어 있습니다. 키와 몸무게를 이용한 자동 계산은 구현되어 있지 않습니다.

## 파일 구성과 실행 방법

```text
README.md                 # 이 설명서
modules/                  # 소스 코드 폴더
├── __init__.py           # 파이썬 패키지 표시
└── health_db.py          # 모듈 1: 건강정보와 파일 입출력 코드
data/                     # 결과 파일 폴더
├── health_data.json      # JSON 형식으로 저장한 결과
├── health_data.csv       # CSV 형식으로 저장한 결과
├── health_data.txt       # TXT 형식으로 저장한 결과
└── health_data.pkl       # PICKLE 형식으로 저장한 결과
assets/                   # 이미지와 문서 리소스 폴더 (현재 비어 있음)
참고/                     # 제공된 참고 자료
```

터미널에서 프로젝트 루트 폴더로 이동한 뒤 다음을 실행합니다.

```bash
python -m modules.health_db
```

파이썬 표준 라이브러리를 사용하므로 별도의 라이브러리를 설치할 필요는 없습니다. 실행하면 각 형식에서 읽은 정보와 `원본과 일치: True`가 출력되고, 네 형식이 모두 일치하면 마지막에 다음 문구가 나옵니다.

```text
검증 결과: 4가지 파일 모두 원본과 일치
```

`data` 폴더가 없으면 실행할 때 만들어집니다. **같은 이름의 결과 파일이 이미 있으면 실행할 때 예시 데이터로 덮어씁니다.**

## 코드를 쉽게 이해하기

### 1. 한 사람의 건강정보 카드: `HealthRecord`

`HealthRecord`는 한 사람의 정보를 담는 **카드의 설계도**입니다. 코드에서는 다음처럼 카드를 만듭니다.

```python
HealthRecord("홍길동", 1995, "남", 175.0, 72.5, 23.67, "과체중")
```

각 값은 순서대로 이름, 태어난 해, 성별, 키, 몸무게, BMI, 비만도 상태를 뜻합니다.

| 항목 | 뜻 | 예시 |
| --- | --- | --- |
| `id` | 식별번호 | `P2026-0001` |
| `name` | 이름 | `홍길동` |
| `birth_year` | 태어난 해 | `1995` |
| `gender` | 성별 | `남` |
| `height` | 키(cm) | `175.0` |
| `weight` | 몸무게(kg) | `72.5` |
| `bmi` | BMI 값 | `23.67` |
| `status` | 비만도 상태 | `과체중` |

`@dataclass`는 이렇게 정보를 담는 카드를 편하게 만들 수 있도록 파이썬이 필요한 기능을 만들어 주는 표시입니다. `str`은 문자열, `int`는 정수, `float`은 소수점이 있는 숫자를 뜻합니다.

카드를 처음 만들 때 `id`는 빈 문자열입니다. 나중에 카드 목록에 추가할 때 식별번호가 붙습니다.

### 2. 카드에 이름표 붙이기: `FIELDS`, `to_dict()`, `from_dict()`

`FIELDS`에는 파일에 저장할 항목 이름이 순서대로 들어 있습니다. 예를 들면 `id`, `name`, `birth_year` 등입니다.

`to_dict()`는 카드의 내용을 **딕셔너리**로 바꿉니다. 딕셔너리는 `이름표: 값` 형태로 정보를 담는 자료형입니다. 변환한 결과는 다음과 같습니다.

```python
{
    "id": "P2026-0001",
    "name": "홍길동",
    "birth_year": 1995,
    "gender": "남",
    "height": 175.0,
    "weight": 72.5,
    "bmi": 23.67,
    "status": "과체중"
}
```

실제 `to_dict()`의 핵심 코드는 다음과 같습니다.

```python
return {field: getattr(self, field) for field in FIELDS}
```

`FIELDS`에서 항목 이름을 하나씩 꺼내고, `getattr()`으로 카드에 들어 있는 값을 찾아 `이름표: 값`으로 묶습니다. 예를 들어 `getattr(self, "name")`은 `self.name`에 들어 있는 이름을 찾습니다.

`from_dict()`는 반대로 파일에서 읽은 딕셔너리로 `HealthRecord` 카드를 다시 만듭니다. 항목이 맞는지 확인하고, 태어난 해를 `int`, 키와 몸무게 등을 `float`으로 바꾸어 복원합니다.

### 3. 카드 목록을 관리하기: `HealthRecordManager`

`HealthRecordManager`는 여러 사람의 카드를 모아 관리하는 **수첩**이라고 생각하면 됩니다. 카드를 목록에 추가하고 파일에 저장하거나 파일에서 읽는 작업을 관리합니다.

```python
self.records = []
```

이 코드는 처음에 빈 카드 목록을 만듭니다. `self`는 지금 작업하고 있는 카드나 수첩 자신을 가리킵니다.

`add_record()`는 카드에 식별번호를 붙이고 목록에 추가합니다. 번호는 실행 시점의 연도와 순번으로 만들며, 현재 수첩에 있는 번호를 확인하여 사용하지 않은 순번을 고릅니다. 예를 들어 2026년이면 `P2026-0001`, `P2026-0002`처럼 만들어집니다.

수첩에는 다음 기능도 있습니다.

- `to_dict_list()`: 모든 카드를 딕셔너리로 바꾸어 목록으로 돌려줍니다.
- `display_records()`: 카드 목록을 화면에 출력합니다.
- `_restore_records()`: 파일에서 읽은 딕셔너리 목록을 카드 목록으로 복원합니다.
- `_load_failed()`: 읽기 오류를 출력하고 현재 수첩을 빈 목록으로 만든 뒤 돌려줍니다.

### 4. 네 가지 형식으로 저장하고 읽기

| 형식 | 파일 | 저장 모습 | 관련 메서드 |
| --- | --- | --- | --- |
| JSON | `health_data.json` | 항목 이름과 값이 함께 적혀 있어 읽기 쉬움 | `save_json()`, `load_json()` |
| CSV | `health_data.csv` | 첫 줄에 항목 이름이 있고 값들을 쉼표로 구분 | `save_csv()`, `load_csv()` |
| TXT | `health_data.txt` | 항목 이름 줄 없이 값들을 쉼표로 구분 | `save_txt()`, `load_txt()` |
| PICKLE | `health_data.pkl` | 파이썬이 읽는 이진 파일에 딕셔너리 목록을 저장 | `save_pickle()`, `load_pickle()` |

CSV와 TXT는 파이썬의 `csv` 기능을 사용합니다. TXT에는 CSV와 달리 항목 이름 줄을 쓰지 않습니다. PICKLE 파일은 직접 저장한 파일처럼 **신뢰할 수 있는 파일만** 읽어야 합니다.

예를 들어 JSON 저장의 핵심 코드는 다음과 같습니다.

```python
with open(file_path, "w", encoding="utf-8") as file:
    json.dump(self.to_dict_list(), file, ensure_ascii=False, indent=4)
```

- `open(..., "w")`는 파일을 쓰기 위해 엽니다. 같은 이름의 파일이 있으면 내용을 덮어씁니다.
- `to_dict_list()`는 카드 목록을 딕셔너리 목록으로 바꿉니다.
- `json.dump()`는 그 목록을 JSON 파일에 저장합니다.
- `ensure_ascii=False`는 한글이 읽기 쉬운 형태로 저장되도록 합니다.
- `indent=4`는 내용을 들여쓰기하여 보기 좋게 만듭니다.
- `with`를 사용하면 파일 작업이 끝났을 때 파일이 자동으로 닫힙니다.

반대로 `load_json()`은 파일을 열어 읽고, 딕셔너리 목록을 다시 카드 목록으로 복원합니다. 다른 형식도 저장 방식은 다르지만 비슷한 순서로 동작합니다.

### 5. 파일 오류 처리하기: `try`와 `except`

`try`에는 실행해 볼 작업을 적고, `except`에는 그 작업에서 오류가 났을 때 할 일을 적습니다.

예를 들어 파일이 없거나 내용이 손상되어 읽을 수 없으면 오류 메시지를 출력합니다. 그리고 그 관리자의 현재 목록을 비운 뒤 빈 목록 `[]`을 반환합니다. 저장에 성공하면 `True`, 저장에 실패하면 `False`를 반환합니다.

### 6. 모든 기능을 순서대로 실행하기: `main()`

`main()`은 앞에서 만든 기능들을 순서대로 실행하는 곳입니다.

1. `HealthRecordManager()`로 빈 수첩을 만듭니다.
2. `HealthRecord(...)`로 예시 카드 두 개를 만들고 `add_record()`로 추가합니다.
3. 원본 목록을 출력하고 `original`에 딕셔너리 목록으로 보관합니다.
4. 각 형식으로 원본을 저장합니다.
5. 형식마다 새로운 수첩을 만들어 파일을 읽고 출력합니다.
6. 읽은 목록과 `original`을 `==`로 비교합니다.

`formats`와 `for` 반복문을 사용해 네 형식에 대한 작업을 차례로 실행합니다. 반복문에 있는 다음 코드는 처음 보면 낯설 수 있습니다.

```python
getattr(manager, save_method)(file_path)
```

`save_method`에 적힌 이름의 저장 기능을 찾아서 실행한다는 뜻입니다. 예를 들어 `save_method`가 `"save_json"`이면 다음과 같은 일을 합니다.

```python
manager.save_json(file_path)
```

비교 결과가 같으면 `원본과 일치: True`가 출력됩니다. 네 형식 모두 일치해야 최종 검증이 성공합니다.

파일 맨 아래의 `if __name__ == "__main__":`은 이 파일을 직접 실행할 때 `main()`을 시작하는 부분입니다. 파일을 다른 파이썬 코드에서 불러오기만 할 때는 `main()`이 자동 실행되지 않습니다.
